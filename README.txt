SETUP INSTRUCTIONS
-------------

STEP 1 — Create Your Bot
1. Go to https://discord.com/developers/applications
2. Click "New Application" > Name it Shia
3. Go to "Bot" tab > Add Bot > Enable "Message Content Intent"
4. Go to "OAuth2" > URL Generator > Select:
   - bot
   - applications.commands
   - Permissions: Read Messages, Send Messages, Manage Messages, View Channels
5. Copy and invite the bot to your server

STEP 2 — Get OpenAI API Key
1. Go to https://platform.openai.com/account/api-keys
2. Create a new API key and copy it

STEP 3 — Railway Hosting (Recommended)
1. Go to https://railway.app
2. Create a new project > Deploy from GitHub
3. Upload this entire folder to a new GitHub repo
4. In Railway, go to "Variables" and add:
   - DISCORD_TOKEN = your Discord bot token
   - OPENAI_API_KEY = your OpenAI key
   - OWNER_ID = your Discord user ID (right-click yourself > Copy ID)
   - BOT_NAME = Shia

STEP 4 — Go Live
Once deployed, Shia will DM you when you join. Talk to her in DMs.
She will remember everything. She is fully yours.
